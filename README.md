## About

Founder of Qualia Bits, building voice AI for Indian call centres in Hindi, English and Hinglish. I build agents and retrieval systems, and I spend a lot of time taking agents apart to see where they break. Before this, computational chemistry at IIT (BHU): molecular dynamics on zinc battery electrolytes.

## Selected builds

- [upgrade-oracle](https://github.com/Kulraj69/upgrade-oracle) - prototype: an agent that reads real changelogs to find which breaking changes hit your code, with citations.
- [bug-compass](https://github.com/Kulraj69/bug-compass) - experiment: how far does a fix sit from what the issue names? A localization-radius atlas over SWE-bench Lite.
- [asli-byaaj](https://github.com/Kulraj69/asli-byaaj) - prototype: paste a loan offer, see the APR it really implies, red flags and regulated alternatives. English + Hindi.
- [taste-twin](https://github.com/Kulraj69/taste-twin) - prototype: an agent that plans a weekend from your taste using Qloo, with a receipt for every pick.
- [leash](https://leash-8btm.vercel.app) - prototype simulation, no real funds: a spending firewall for AI agents on NEAR with plain-English policy and function-call keys.
- [KSDB](https://github.com/Kulraj69/KSDB) - exploration: a vector database with semantic caching, memory layers and graph-linked chunks.
